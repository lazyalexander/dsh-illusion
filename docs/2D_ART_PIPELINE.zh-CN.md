# 2D 美术生产线

[English](2D_ART_PIPELINE.md) | 简体中文

Illusion 负责可审阅的生产线，不占有视觉作者身份。作者拥有风格意图；Illusion 把意图整理成版本化 Style Contract，供生成提供者和验证器共同使用。

## 风格决定权

- `author`：作者直接提供并批准契约。
- `shared`：作者与 Illusion 一起把视觉特征具体化，最后仍由作者批准。
- `illusion-proposal`：Illusion 在信息不足时提出候选；作者确认前不能变成 `accepted`。

契约记录色板、线条、形状语言、明暗、纹理、光照、不变量、排除项，以及权利状态为 `owned`、`licensed`、`public-domain` 或 `unknown` 的参考来源。优先记录可观察的视觉特征，而不是只写一个作者名字。权利不明的参考会持续显示，不能被当作默认许可。

## 生产阶段

1. 需求：交付类型、画布、透明度、目标引擎和用途。
2. 风格：创建或选择已经接受的 Style Contract。
3. 构图：轮廓、视觉中心、镜头和留白。
4. 草稿：生成提供者创建第一份可审阅视觉产物。
5. 按风格分流：
   - 像素风：像素清理、色块控制、色板和边缘校验。
   - 日漫/自定义栅格：线稿、上色、渲染和一致性检查。
6. 需要时切分：Sprite 帧、Tile、锚点和图集区域。
7. 验证：确定性检查加作者明确的视觉验收。
8. 导出：只从已接受检查点交付。

每个已发布阶段都必须保留在历史中，并支持文字反馈、参考文件反馈、分支和导出。后续图像提供者适配器负责真正的栅格生成；本版本实现与提供者无关的 Style Contract、规划规则、治理和验证夹具，不声称 DeepSeek 单独就能渲染完成品。

## 证据边界

Illusion 可以证明尺寸、色板声明、透明意图、帧布局、参考来源字段和生产历史；不能自动证明艺术质量、原创性、参考授权、角色吸引力或目标引擎中的最终观感。这些需要作者验收或外部回执。
