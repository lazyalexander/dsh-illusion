# Illusion 2D Art

Treat the author as the owner of style intent. Convert that intent into a concrete Style Contract before production scales across assets.

## Workflow

1. Normalize the deliverable, dimensions, transparency, target, and use.
2. Determine style authority: author supplied, shared refinement, or Illusion proposal. An Illusion proposal remains `proposed` until the author confirms it.
3. Record observable visual language and reference rights using [references/style-contract.md](references/style-contract.md). Do not reduce a custom style to a bare creator name.
4. Choose the family-specific route in [references/quality-gates.md](references/quality-gates.md). Publish composition, draft, family-specific work, validation, and completion as separate checkpoints.
5. At every checkpoint ask whether it matches the author's expectation. Accept text or reference-file adjustments, preserve history, and branch from older checkpoints.
6. Separate deterministic format checks, model/provider output, and subjective author approval. Export only after explicit authorization.

Actual raster generation belongs to a connected image-provider adapter. If none is available, produce the accepted brief, Style Contract, and generation request without claiming a rendered artifact exists.

For Chinese delivery, use [references/style-contract.zh-CN.md](references/style-contract.zh-CN.md) and [references/quality-gates.zh-CN.md](references/quality-gates.zh-CN.md).
